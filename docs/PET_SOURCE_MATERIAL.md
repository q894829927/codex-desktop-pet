# V0.3-C source material

The desktop pet pose sheet at `public/assets/pet/poses14.webp` is derived directly from the user-provided V0.3-B material sheet. It uses a fixed 7x2 grid, each cell 192x288, in this order:

Top row: idle-1, idle-2, idle-3, blink, blink-half, thinking, happy.
Bottom row: wave, excited, success, tap, double-jump, sleepy, rest.
